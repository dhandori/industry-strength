# 시장 흐름판

한국·미국 세부 산업(구성 종목 같은 비중 바구니 지수)의 강도를 매일 순위로 보여주는 추세추종용 대시보드.

- 화면: GitHub Pages (`docs/` 폴더)
- 갱신: GitHub Actions가 평일 한국장 마감 후(16:40·18:10 KST)와 미국장 마감 후(06:50 KST)에 자동 실행
- 데이터: Yahoo Finance 종가(실패 시 한국은 네이버, 미국은 stooq)

## 화면 구성

- **📊 산업 강도** 탭: 아래 '계산 방법'의 세부 산업 강도 순위. 맨 위 **산업 흐름** 카드(`docs/flow.js`)는 같은 순위 이력(`history.rank`)만으로 큰 분류 간 강도 이동(로테이션 지도·분류별 40거래일 선)과 5·20·60일 순위 이동이 큰 세부 산업을 보여 준다. 분류 강도 = 분류 안 세부 산업 순위 백분위 평균의 5일 평균.
- **🚀 52주 신고가** 탭(`docs/highs.js`, `docs/data/highs.json`): 한국·미국 52주 신고가 종목의 흐름(신고가 수 추이, 강해지는 업종, 업종×날짜, 자주 나온 종목, 날짜별 명단). 데이터는 이 저장소의 Actions가 아니라 dhandori/global-high-radar 의 '52주 신고가 기록' 예약 작업이 한국장 17시·미국장 08시 기록 뒤 `docs/data/highs.json` 한 파일만 올린다. 두 탭은 시장 선택(한국/미국)과 산업 상세 서랍만 공유한다.
- **🤖 AI 시장** 탭(`docs/ai.js`, `docs/data/ai_market.json`): OpenAI·Anthropic 매출 런레이트(Epoch AI), 오픈웨이트 vs 클로즈드 토큰 비중(OpenRouter, 주간), 토큰 비중 vs 지출 비중(Vercel AI Gateway, 매일). `scripts/ai_market.py`를 `.github/workflows/ai-market.yml`이 매일 09:20·12:20 KST에 돌린다. 텔레그램 알림(새 매출 보도·월요일 주간 요약)은 dhandori/wamo_claude_bot 의 `scripts/ai_market_alert.py`가 이 JSON을 읽어 보낸다.

## 계산 방법

| 항목 | 정의 |
|---|---|
| 5·20·60일 순위 | 해당 거래일 수 동안의 종가 수익률을 시장 안 세부 산업끼리 비교한 순위 (매일 기간이 하루씩 밀리는 롤링 방식) |
| 종합 강도 | 5일·20일·60일 수익률의 백분위를 20%·40%·40%로 가중 평균 (0~100). 60일 이력이 없으면 남은 기간으로 가중치 재조정 |
| 상위권 | 종합 순위 상위 25% |
| 200일 수익률·순위 | 200거래일 종가 수익률과 시장 안 세부 산업끼리의 순위 (산업 순위 표의 '200일' 정렬) |
| 종목 RS 지수 | 산업 RS 지수와 같은 오닐식 가중(최근 3개월 40%·6·9·12개월 각 20%) 수익률을 시장 안 전체 종목끼리 비교한 1~99 백분위. 'RS 강한 종목' 박스에서 RS·당일·5·20·60·200일 순으로 정렬 |
| 상위권 지속 | 상위권에 연속으로 머문 거래일 수와 시작일 |
| 추세 점검 | 가격>50일선, 50일선>150일선, 150일선>200일선, 200일선이 20거래일 전보다 위, 52주 고점 대비 -15% 이내 |
| 단계 | 상승 추세 / 상승 전환 시도 / 상승 둔화 / 하락 추세 / 바닥 다지기 (`scripts/update.py`의 `stage_of`) |
| 바구니 지수 | 구성 종목 하루 수익률의 단순 평균을 매일 이어 붙인 지수(시작 100). 가격이 있는 종목이 2개 이상인 날부터 계산 |
| 종목 확산 | 구성 종목 중 50일선 위 비율, 52주 고점 -5% 이내 종목 수 |
| RS선 | 바구니 지수 ÷ 시장 지수 ETF 종가 (한국 KODEX 200, 미국 SPY) |
| 신호 | 순위 급상승(5일 새 max(5, 산업 수×15%) 계단 이상), 신규 상위권, 상위권 이탈, 52주 신고가(고점 대비 -1% 이내), RS 신고가, 50일선 돌파·이탈(최근 5일) |

순위 이력은 저장된 가격(`data/prices/`)으로 매번 처음부터 다시 계산하므로, 실행이 하루 빠져도 다음 실행에서 자동으로 메워진다.

## 산업 목록 바꾸기

`scripts/build_baskets.py`의 KR·US 목록을 고친 뒤 `python scripts/build_baskets.py <global-high-radar 경로>`로 `config/baskets.json`을 다시 만들고 push하면 바로 다시 계산된다. 한국 분류는 global-high-radar의 산업 분류표(data/industry_business_registry.json)를 따른다.

## 직접 실행

```
pip install -r requirements.txt
python scripts/update.py              # 수집 + 계산
python scripts/update.py --no-fetch   # 저장된 가격으로 계산만
```

투자 판단의 참고 자료이며 매수·매도 추천이 아니다.
